### Corrección de tarifas
Los estudios previos pueden contener simulaciones a USD50/kg para muebles o USD15/kg integral. **La instrucción vigente del usuario es USD15/kg para contenedor marítimo Home y USD50/kg para tecnología aérea con impuestos.** No se ha confirmado si USD15/kg marítimo incluye aranceles ni impuestos, de modo que el margen sigue condicionado hasta cotización escrita.
