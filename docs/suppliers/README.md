# Proveedores y abastecimiento

Proveedor sugerido no equivale a contrato. La [matriz de 30 productos](../research/CATALOGO_30_SOURCING_MARGENES_2026-11-07.md) contiene fuentes de estudio, precios indicativos y enlaces.

Antes de activar cada proveedor comprobar: identidad y razón social, presupuesto escrito, MOQ, entrega directa al comprador, disponibilidad real, país de origen, muestra, garantía, reposición, embalaje, peso físico/volumétrico, seguro y condiciones fiscales.
