Calcular diferencia entre tarifa pagada a importador y costo neto contable según factura; separar IVA venta, IIBB, cobros, anuncios, flete local, reserva devoluciones y garantías.

Ningún margen del estudio es garantía de rentabilidad hasta medir adquisición y costos reales.
